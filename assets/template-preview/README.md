# Pratinjau template homepage

Gambar JPG di folder ini adalah cuplikan cover renderer AsProject, diambil dari URL lokal `undangan.html?demo=1&tpl=<id>&kartu=1` pada viewport ponsel. Cover demo dipasangkan dengan foto contoh tiap tema agar variasi visualnya terlihat. Semua nama, tanggal, dan detail acara di dalam gambar adalah data contoh; gambar ini bukan portofolio atau dokumentasi undangan pelanggan.

Daftar tema dan pemakaian gambar di homepage ada di `assets/marketing.js` pada array `FEATURED`. Perbarui cuplikan dari renderer bila desain template berubah.
